## 1. 目标与问题

X04b 已采用 Q_mix。部署候选为 H_ref(Q_mix) = Q-A + Q-AV + A3 + V2 + V1，和精简版 H3(Q_mix) = Q-AV + A3 + V2；专家一律为 X04a D1。本轮回答四个问题：

1. **校准：** 系统给出的置信度是否可信？
2. **拒识：** 什么时候该说"不确定"？代价是多少覆盖率？
3. **缺失模态：** 没有人脸或没有语音时，系统是否仍然可靠？
4. **迁移误差：** 参数搬到最终模型、搬到其他语料上时偏差多大？

## 2. 继承与边界

- 冻结的划分与规则不变：`folds_v1.json`、`x03_inner_val_subsets.json`、`x03_face_missing_policy.json`。
- **方法选择只在 ET 交叉验证的 OOF 上做。** ET-test、MER-test、SIMS-valid 只报告，零拟合、零选择；SIMS-valid 在本轮不承担任何决定。CH-SIMS test 零推理；旧目录只读。
- 拟合规则：参数要么用不少于 4 折合并的 OOF 拟合，要么用**同一模型**对其未训练过的说话人的预测拟合。
- 主指标与以前相同：7 类 macro-F1、UAR、WA、逐类 P/R/F1、中性误报率；拒识计入召回分母，同时报告覆盖率；说话人整群 bootstrap 2,000 次，种子 20261011。
- 工作区不干净就拒绝启动；每次运行写 run_meta。

## 4. CPU

### 第一段：方法开发与冻结（立即开始，用 Q_et 的五折系统）

Q_et 与 D1 专家都有完整五折 OOF（15 名说话人）。评估时用"留一折"：评估第 k 折时，参数只用其余 4 折合并的 OOF 拟合。方法选定后写进 `x05_method_freeze.json` 并提交，**之后不再修改**；提交时间必须早于第二段的任何 Q_mix 分析。

**C1. 校准方法。**
- 候选：(a) 只用温度；(b) 温度加 7 类偏置（现行方法）；(c) 逐类温度加偏置。融合权重与校准参数分别拟合，做法与现有实现一致。
- 选择规则（预先登记）：留一折 NLL 最低者；与最低者相差在 0.002 以内的，选更简单的那个。
- 报告：NLL、Brier、top-label ECE（15 个等宽箱）、逐类 ECE、可靠性图。

**C2. 决策与置信度的定义（固定，不做选择）。**
- 标签 = OP-N 工作点下的 argmax（"真实中性被判为非中性 = 0.15"）。
- 置信度 = 校准后的概率中，所选标签的那一项；同时报告它的 ECE（以"所选标签是否正确"为结果）。

**C3. 选择性预测。**
- 主置信度为 C2 的定义；第一与第二概率之差只作为次要对照。
- 报告：风险-覆盖曲线、AURC；被接受样本的 macro-F1 随覆盖率的变化；拒识计入召回分母时的 macro-F1。
- 两个工作点：**OP-R90 与 OP-R80**，即拟合集上覆盖率为 90% 与 80% 的阈值。

**C4. 中性工作点曲线（只报告）。** 主工作点保持 OP-N 0.15；另报中性误报目标为 0.05、0.10、0.20、0.25 时的 macro-F1 与非中性宏召回。

**C5. 缺失模态。**
- 两套回退系统：
  - **H_A**（无人脸）= Q-A + A3；
  - **H_V**（无语音，例如 X06 的静默期）= Q-V + V2 + V1。
- 两种做法都要算：(i) 沿用全系统参数，缺失分量按现行规则填均匀分布；(ii) 回退系统单独拟合自己的全部参数。部署一律用 (ii)；(i) 用来量化差距。
- 对照：H_A 与 Q-A、A3 单独相比；H_V 与 Q-V、V2 单独相比。
- 按人脸质量五分位（`utterance_quality.jsonl` 与 X02 人脸统计）分层，报告全系统与 H_A 的 macro-F1。只报告；是否加"人脸质量差就回退"的规则由 reviewer 决定。

**C6. 守门函数。**
- 纯函数：输入为是否有脸、人脸个数、人脸质量、是否有语音；输出为路由（全系统 / H_A / H_V / 拒绝）以及原因。
- 固定规则：无脸且无语音 → 拒绝；人脸个数 > 1 → 拒绝，原因 `multi_face`（留到 X08）；其余按可用模态路由。
- 只做单元测试和现有数据上的触发率统计。

### 第二段：部署参数包（G 完成且方法冻结之后）

**C7. 拟合部署参数包（Q_mix）。** 对象：H_ref、H3、H_A、H_V。按冻结的方法：
- **融合权重与校准参数：** 用 Q_mix 两折 OOF（6 名说话人）加 FMH（3 名说话人）合并拟合；
- **中性偏置与 OP-R90/OP-R80 阈值：** 只用 FMH 拟合。理由是这几项对模型差异最敏感，X04b 的 ET-test 漂移主要出在这里，而 FMH 正是部署模型本身在未训练说话人上的输出。
- 评估：在 FMH 内按说话人留一，即用另外 2 名说话人加两折 OOF 拟合、应用到第 3 名。3 名说话人的区间只是描述性的。
- 对照：只用两折 OOF 拟合全部参数（即 X04b 的做法）在 FMH 上的结果，用来说明改用 FMH 的收益。
- 产出 `calibration_bundle_v1.json`：各分量与 adapter 的 SHA；融合权重；校准参数；中性偏置；OP-R90 与 OP-R80 阈值；守门规则；拟合集与 `x05_method_freeze.json` 的 SHA。
- 提供 `emotioncore.x05.bundle.apply(component_probs, availability) -> (label | reject, confidence, route)`，X06 会直接调用它。

**C8. 迁移误差（只报告）。** 参数包原样应用到以下数据，报告 ECE、NLL、中性误报率与 0.15 的偏差、OP-R90/OP-R80 的实际覆盖率，以及被接受样本的 macro-F1：
- ET-test（含逐说话人）；
- MER-test：在 5 个共享类上重新归一化，中性误报以 MER 的 neutral 计算；
- SIMS-valid：标签为 0 的片段被判成非中性的比例；阈值下的覆盖率；全部片段与被接受片段的 Pearson。

## 5. 通过门槛（reviewer 判断，agent 只呈现）

- **方法层面**（Q_et 五折，留一折）：H_ref 与 H3 的所选标签置信度 ECE ≤ 0.03，OP-A 的 top-label ECE ≤ 0.03；OP-R90 的实际覆盖率在 90% ± 3 个百分点之内；H_A 不低于 Q-A 与 A3 中较好者减 0.01；H_V 不低于 Q-V 与 V2 中较好者减 0.01。
- **部署层面**（Q_mix，FMH 内按说话人留一）：中性误报在 [0.10, 0.20] 之内；OP-R90 的覆盖率在 90% ± 5 个百分点之内。
- 参考：X03 五折系统在 CV 上的 ECE 已在 0.013–0.019，ECE 门槛只是底线检查。任何部署系统在 FMH 或 ET-test 上的 ECE 超过 0.05，都要在第 11 节单独列出。
