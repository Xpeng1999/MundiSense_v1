# X06a 执行口径

以下执行细节在读取任何本轮模型输出之前登记；不增加方法选择来源。

- 间隔随机种子使用 20261011，各说话人以 seed + speaker_id 派生随机流；句序按 group、dialogue、utt_id 排序。
- MP4 原始时长定义真值区间；WAV 原始时长单独记录。两者原本不完全一致，构造流时不更改真值时长，不把静音填充当成新的真值句。
- VAD 语音阈值的数值集合原文未给出，采用概率阈值 {0.3, 0.5, 0.7}，与最短静音 {0.2, 0.4, 0.8} 做笛卡尔积；两候选共享最短语音 0.3 秒、最长 15 秒。只在 AISHELL-4 train 选择。
- AISHELL-4 RTTM 重叠帧不计入评估，并在重叠区间断开 VAD 状态；无语音帧保留为负类。第 0 通道，不使用说话人识别模型。
- 启动预算使用既有 Q_mix / X02 耗时，保守计入常驻 GPU 进程的等待和 CPU 处理时间；全速阶段先做 CPU 人脸预处理再加载 GPU 模型。VAD 实际段数产生后重新核对预算，超过 15 小时即停止。
- v1.1 只替换 JSON 顶层 gate_rules 值的原始字节区间，不重序列化其他字段；H3 默认值和 H_V 的 OP-R80 策略均放在 gate_rules 中，v1 原文件不改。
- S6 使用正确切句、无平滑，先比较与 X05 同口径的逐句决策，再单列新守门规则造成的拒绝。若协议所要求的逐句一致率低于 0.95，立即停止；不会将差异句移出分母。
