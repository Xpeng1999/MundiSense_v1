# X06b 启动前登记

本文件在读取任何 X06b 模型输出或候选结果前登记；不扩展 reviewer 授权范围。

- 只执行 H3；保持 v1.1、FSMN/0.3/0.4 秒、α=0 的原始文件和 SHA。全部新产物位于 H 盘 X06b；X06a 和更早目录只读。
- R2 两候选固定为 1/2、1/3；并行检测固定 8 个独立 YuNet 实例，最多 16 帧在途，不把线程数作为结果驱动的额外网格。不使用 NVDEC，R2 为 CPU 工作，不记为 GPU 占用。
- 顺序解码按全局 5 fps 时刻选择最近原生帧，末帧持续到片段结束，间隔保持原片段最后一帧。底层解码器可能必须读取依赖帧，但只取出和处理 5 fps 帧，不随机反复 seek；原像素分辨率不变。
- R2 使用 X06a 三条完整 FMH 流，包括间隔。目标轨迹按正确切句的每句与每个间隔分别排名；参考是原 YuNet、原分辨率及 X02 关联/排序规则在同一采样时刻的输出。两候选共用参考，不使用 ET-test。
- IoU 分母为新旧目标轨迹有框帧的并集；单边缺框计 IoU=0，双边无框不计 IoU，另报帧数。不通过交集丢掉候选漏检。报告中位数和 >=0.7 比例。吞吐合格者按比例最高选择，完全相同则选 1/2；没有合格候选就停止。
- 吞吐为实际有界解码与并行检测流水线的墙钟/全部媒体时长，包含初始化和收尾；另报解码、检测工作量。原管线参考测量与 IoU 分析单列，不混入候选吞吐；逐帧小型框结果留服务器。
- 保留 X02 JPEG78 往返后的原分辨率裁剪像素及 crop expansion/448/quality85 等操作；改为帧到达即关联并为轨迹写裁剪，段末仅排序和选择；不在内存保留整段或整流 JPEG 帧。
- R4 种子为 20261013。同场次两目标句之间按 utterance ID 最后一个数值字段的句序号收集其他说话人句子；换人次数包括目标→他人、他人之间发生说话人变化、他人→目标，每次独立 U(0.3,1.0)；没有其他句只加一次停顿。跨场次为3秒。仅使用其他说话人的时长与ID计算间隔，不渲染其媒体、不推理其样本。
- R4 正确切句对照也在同一新流上计算，避免全局抽帧相位和底噪差异混入 VAD 损失；计入预算。旧拼接流保留作最坏参考。
- 预算计 GPU 子进程完整墙钟，包括加载、CPU等待和实时等待；CPU-only 步骤单列。未来工作按历史实耗保守估算加20%与300秒，不默认已优化到实时。各阶段后重估，预计超过14小时就不启动下一GPU阶段。
- R5 统一从输入启动开始计墙钟，包含末事件排空，不截去末端延迟来满足<=1.0。内存以输入启动后第600秒首次采样为基线，报告结束及后续峰值；不修改暖机长度。前/后半程积压分别用输入时间划分，报告P95与曲线。

- R3 沿用 X06a S6b 的全 H3、无模态/多脸守门 OP-N/R90 比较；无脸时 Q-AV 复用同一次 Q-A 的概率，V2 为冻结的均匀缺失值，不额外跑 H_ref 分量。实际部署守门输出另外保存。
