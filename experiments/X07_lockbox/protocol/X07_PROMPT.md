### L3. 开发集预演（SIMS-valid，647 条）

- 预演通过后才进入 L4。

### L4. 封存集推理（只做一次）

- 对全部 1,034 条片段推理一次，系统为 H3；同一次前向中顺带计算两个次要系统：H_A（只用声音）、H_V（只用画面）。
- 所有推理完成之前，不得计算或查看任何指标。若因基础设施故障（OOM、进程崩溃等）中断，可以用同一代码与配置从断点续跑，并记录原因；不得重跑已完成的片段。
- 推理完成后，用冻结的脚本计算一次全部指标。**指标算出后，不得以任何理由重跑或修改。**

**指标：**
- **主指标：** H3 在媒体可用片段上的 Pearson。
- **次要指标：**
  - Spearman；
  - Acc-2：排除标签为 0 的片段，比较符号；
  - 全部 1,034 条的 Pearson：缺媒体或解码失败的片段按均匀概率计分；
  - OP-R90 的覆盖率，以及被接受片段的 Pearson；
  - 标签为 0 的片段被判为非中性的比例（按 OP-N 标签）；
  - H_A、H_V 的同样指标。
- **区间：** 按视频整群 bootstrap，以片段 ID 中 `__` 之前的部分为视频，2,000 次，种子 20261014。
- **同表对照：** L3 的 SIMS-valid 结果、X06b 部署配置在 ET-test 上的 7 类结果（直接引用，不重跑）。

## 4. 通过门槛（预先登记，reviewer 判断）

- H3 主指标：Pearson ≥ 0.75，且视频整群区间下界 ≥ 0.70；
- H3 的 Acc-2 ≥ 0.80。

依据：SIMS-valid 上同一系统的 Pearson 约 0.82、Acc-2 约 0.84。门槛留出约 0.05–0.07 的余量，用来容纳开发集到测试集的正常差异。
