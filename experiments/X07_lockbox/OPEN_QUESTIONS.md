# X07 冻结前的口径说明

以下保守解释在任何 SIMS 推理前登记，之后不得依据结果调整。

1. 根分区 80 GB 门禁指执行所有数据处理与推理的 WSL GPU 服务器，沿用 X04–X06b 的 `storage_gate`；本地 Mac 仅存代码与摘要。GPU 预算按守护进程子进程完整墙钟累计（包括模型加载与等待），上限 14,400 秒。
2. 所有片段按一句处理；不运行 VAD，不对片段语音存在性另作选择。音频提取为 16 kHz 单声道浮点 WAV。画面沿用 X06b 5 fps 原生帧索引、YuNet 1/2、8 检测实例、原分辨率裁剪及 Q 八帧构造。
3. H3 保留冻结部署规则：无脸回退 H_A；多人脸歧义仍算原概率，但 OP-R90 拒识。主指标媒体可用指音视频文件存在且可完整经过既定解码准备；不因低置信度或多脸移除。缺媒体/解码失败的片段在三个系统均不可用，全部样本 Pearson 用均匀概率（情绪倾向 −3/7）。H_V 无脸也标记不可用并用均匀概率；H_A 不使用画面或多脸门禁进行决策。
4. Acc-2 分母为该划分全部标签非零的片段。沿用 X01 `sims_metrics`：不可用片段及分数恰为零的片段计错；可用片段比较正负号。另报告可用数，禁止因缺媒体缩小 Acc-2 分母。中性误报率分母为全部 label=0 的片段；不可用/无脸导致无标签时不计非中性，按未施加拒识的 OP-N 标签统计可用预测。
5. 按 X07 的“同样指标”对三个系统均报告参数包中既有 OP-R90 阈值；H_V 的这项是固定 R90 统计，不改变部署时静默视觉使用 R80 的配置。每个系统均以校准后、加中性决策偏置之前的概率计算倾向。
6. 全部指标均给出视频整群 95% percentile 区间。每次重采样从全划分的独立视频中等概率、有放回抽取相同数量视频，保留视频全部片段（重复视频重复保留）；随后应用各指标可用性/中性筛选。同一 2,000 组抽样用于三个系统，NumPy default_rng，种子 20261014。退化样本的未定义指标不填零，报告有效 bootstrap 次数；原始点估计未定义则为 null。
7. 一次性指标锁在读任何 label 列之前创建；开始计算后即不允许再次运行，包括计算失败。推理逐片段持久化，只有基础设施中断可按相同代码与配置显式记录原因后恢复，已完成片段不会前向第二次。准备完成与推理完成回执分别核对精确 ID 集及 SHA。
8. L1 先提交完整执行/指标代码，再另提交一次协议；协议记录前一代码提交及逐文件 SHA，后续报告提交不改变执行代码。测试只使用构造数据，无 GPU 试跑和 SIMS-test 指标预览。

以上解释是否均符合 reviewer 的预期，由 reviewer 验收；若结果不满足门槛，不更改任何口径。
