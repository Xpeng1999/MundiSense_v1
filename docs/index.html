What it does

It listens. It looks. It knows when to stay quiet.

Hears the voice

A speech model tuned for Chinese picks up how something is said, not only what is said.

Watches the face

A vision model follows one face through time and reads expression as it changes.

Weighs both together

An audio-visual model takes in sound and picture at once. Then all three opinions are fused.

How it works

Three models. One decision.

Each model votes with a full set of probabilities. A frozen layer fuses them, calibrates the result, and decides whether to answer.

01

Segment

Find where an utterance starts and ends, and pick the target face.

02

Perceive

Run the voice, face and audio-visual models on the same moment.

03

Fuse

Combine their probabilities and calibrate with frozen parameters.

04

Decide

Answer with one of seven labels, or abstain and say why.

Measurement notes

Models. H3 = Q_AV (Qwen2.5-Omni-7B + LoRA) + A3 (Chinese HuBERT) + V2 (CLIP ViT-L/14), frozen fusion and calibration.

CH-SIMS v2. Sentiment labels, not seven emotions. Test n = 1,034; 976 with media. Pearson r 0.792, cluster-bootstrap 95% CI [0.756, 0.829]. All-clip r 0.761. At the frozen threshold 645 of 1,034 clips are accepted (62.4%); 257 of the rejections are multi-face film scenes.

EmotionTalk. 1,929 test utterances, four speakers. Macro-F1 0.645 (no rejection); 0.624 with automatic segmentation at 87.66% coverage.

Latency. Utterance end → last event includes waiting for merged or split segments; it is not time-to-first-feedback. Process memory grew 11.04% after warm-up. No claim for mobile, robot hardware or long-duration use.

Principles

Built to be doubted.

Reading people is a sensitive thing for a machine to do. These are the lines we hold.

01

Expression, not mind-reading

The output describes what can be seen and heard in a recording. It is not a claim about what someone privately feels, and it is not a diagnosis.

02

Doubt is an output

Low confidence, a missing face, or two faces competing all end in an explicit abstention with a reason. Never a quiet default to “neutral.”

03

Tested on people it never met

Test speakers are kept out of training. The film test set was sealed and opened once. Abstentions stay in the denominator.

04

Not for judging people

MundiSense is a research system for responsive machines. It is not meant for hiring, grading, or monitoring people at work or at school.
