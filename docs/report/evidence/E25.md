# 情绪之间 · 中文单人情绪感知 Demo

真实历史结果回放，X07 已于 2026-10-15 验收。核心演示完全本地，无 GPU、SSH、账户或网络依赖，不提供现场上传推理。

## 启动与停止

```sh
cd single_person_demo_v1
./start.sh
```

打开 http://127.0.0.1:8765 。前台按 Ctrl+C 停止，或另一个终端执行 `./stop.sh`。需要其他端口：`PORT=8766 ./start.sh`。仅监听本机，不对外发布视频。Python 3.9+，无需安装包。`public/` 为完整静态产物，Python 服务只为安全路径与视频 Range 提供支持。

## 内容与证据

20 个精选案例：16 个短案例（15 个可播放、1 个原始输入故障），3 段 R5 压力流回放，1 段 R4 同源切句对照。ET 短案例覆盖 02/13/20/21 四名说话人；另含 SIMS 影视与节目片段。精选为解释性选择，不计算案例集性能、不冒充随机抽样。

- `public/data/cases.json`：媒体、源 ID、原始时间范围与显示偏移、真实标注、各系统决策、拒识原因、来源 SHA、说明。
- `public/data/summary.json`：直接摘录 reviewer 审计与 X06b 汇总 JSON；不重新计算正式指标，不随筛选改变。
- `public/data/selected_ids.json`：稳定选例名单。
- `public/media/`：H.264/AAC 展示副本和缩略图，非当时模型输入。
- `scripts/export_server.py`：按固定字段条件和稳定 ID 顺序扫描已有预测；优先分散 ET 说话人。只写服务器独立 `demo_v1`，不导入模型或运行推理。
- `scripts/export.sh`：通过 `ssh wsl` 导出并下载；日常启动无需执行。`prepare_local.py` 摘录原始汇总并生成解释文案。
- `scripts/validate.py`：检查所有媒体完整解码、音轨存在且非全零、时长、SHA、HTTP Range、标签体系与配对 ID。运行时需启动服务及本地 ffmpeg/ffprobe。

## 时间与标签语义

R4 的正确切句与 VAD 归因来自同一流同一源句；归因是实验已有的重叠加权结果，不是假装在当前单句上重跑 VAD。R4 没有真实回放写出时刻，因此显示“暂无时刻记录”，快速模式显示保存决策。

R5 使用原 X06a 短间隔时间线。画面按原片段顺序在 25 fps 展示时间网格重建，间隔保持末帧；声音直接截取原实验 WAV，保留停顿与底噪。画面时间网格误差最多约 40 ms；展示转码未用于任何推理。输出时刻为 `decision_s + scheduled_latency_s`，保留相对原流偏移。媒体结束后统一时钟仍继续到末个输出，支持暂停、拖动与倍速；不会将结果提前放到视频末尾。

SIMS 只有倾向真值，不显示假的七类标注；OP-N 标签读取原始记录，前端不取概率 argmax 替代。H3 无脸回退和 H_V 缺失单独显示。只听声音/静音观看仅改变播放方式，模型对照来自保存的不同系统结果。

## 扩充案例

在导出脚本增加一个可证实条件，登记稳定 ID 与解释。真实输出字段缺失就置空，不能用其他系统分数补齐。如需修改选例，删除或移走相应独立展示副本再转码，绝不改正式实验目录。重新运行导出后执行验证脚本并浏览器抽查。参考 `roadmap_v2/DEMO_IMPLEMENTATION_PROMPT.md`。

## 已知边界

自然静默没有充分配套实测；R5 静默间隔保持末帧。R4 精度与 R5 延迟来自不同构造流，均非自然设备验证。多脸影视仅展示单人假设边界。没有新推理、S01、阈值优化或训练。新方案只列为待验证投入。资料依据以 2026-10-15 reviewer 总评为准，未合并 PR #9。

音频已做全量解码与非零信号检查，浏览器以非静音方式实际播放关键案例；这不等于对所有样本逐字人工听写或独立情绪复标。因果说明只使用记录支持的边界/路线，不凭画面猜测人物内心或说话身份。
