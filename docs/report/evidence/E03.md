## 3. 偏离是否影响结论

标签隔离修订在任何 GPU 推理/真实指标执行前完成；v1 未运行有缺口的指标路径。v2 预登记与独立目录保留了时序。首次 timm 初始化故障没有预测，恢复的是 X06b 同版本依赖，保留 34.095 秒失败用时。两者都不构成结果驱动的选择，不要求返工。

test 40 条缺媒体、18 条原生取帧失败按原规则计分。它们影响输入覆盖，不能当作模型分类错误全盘否定系统，也不能从 Acc-2 分母剔掉来美化成绩。后续可以在新版本改通用输入，但不更改本轮分数。

## 4. 对中文单人最关键的解释

固定规则的 62.379% 全体覆盖分解如下，四种结果互斥：

| 结果 | 条数 | 占全部 1,034 条 |
|---|---:|---:|
| 接受 | 645 | 62.38% |
| 歧义多脸拒绝 | 257 | 24.85% |
| 低置信拒绝 | 74 | 7.16% |
| 媒体不可用 | 58 | 5.61% |

在“媒体可用且未触发歧义多脸”的 719 条中，接受 645 条，即 **89.71%**；Pearson **0.793119**。该子集不是人工确认的自然单人基准，不能作为实机保证，但足以说明不能把 62.4% 全归为中文单人置信度失效。补充 Acc-2 为 87.12%（629 个非零标签）；这是改变分母后的解释性数字，不替代原 81.89%。

H3 与 H_A 在相同 976 条可用媒体上的 Pearson 差 **+0.029140**，配对视频整群 95% CI **[+0.001508, +0.057018]**。这是审查时对冻结输出的解释性分析，没有据此选模型或调参；与此前融合证据一致，继续保留 H3 默认、H_A 回退是合理的。不能只因 H_A 全体覆盖较高就放弃视觉。

主 Pearson 计算包含多脸门禁拒绝的媒体可用片段；实际被接受片段 Pearson 为 0.810012。R90 表示拟合时的覆盖目标，不表示 90% 准确率。

## 5. 这次验收支持什么

支持：本项目训练/校准未使用的 CH-SIMS test 片段上，冻结系统的情绪倾向能力达到事先目标；结合 ET 七类与 X06 工程证据，公开数据阶段可以结项。

不扩张为“整个语料完全未接触”或“新说话人已经验证”。SIMS-valid 已用于前期数据配方决定。身份复核发现 valid 的 120 个视频来源与 test 的 142 个来源共有 **117 个**，test **798/1,034** 条来自这些共享来源；无 speaker_id，来源视频也不等于独立人物。[身份复核](reviewer_audit/takeover_x07_identity_overlap.json)。这是官方划分的解释边界，不是本轮新增泄漏或返工理由。

CH-SIMS 是情绪倾向任务，不能把 Pearson/Acc-2 当作七类识别准确率，更不能称对绝对情绪强度或内心状态完成验证。数据任务定义可参阅 [CH-SIMS v2 原论文](https://arxiv.org/abs/2209.02604)及项目数据卡。
