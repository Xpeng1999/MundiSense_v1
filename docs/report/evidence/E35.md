## 口径

- 节点、连线、层数与流动动画是原工程的 3D 架构示意，颜色映射各模块保存分数，不是内部神经元激活。
- 动画采用原有逐阶段节奏。移除了误导性的统一“慢放×N”；显示的模块耗时来自原记录，音频解码+A3+V2+Q_AV小计不等于端到端或实时设备延迟。
- 两个影视例只有情感倾向真值，没有七类情绪真值；不显示伪造的七类“标注一致”勾选。
- 结尾 macro-F1/accuracy 仍为 EmotionTalk R4 正确切句的完整1,929句评测；新增精选影视片段不进入其分母。
- 没有新训练、推理、阈值选择或 GitHub 发布。公开传播原影视片段的许可尚未核实。

## 文件与复现

`archive_before_sims/` 保存接手时的原脚本、视频和封面。`_src/sims_cases.json` 保存新增案例、来源及原始记录。`build_ms/used_records.json` 保存全部8例、真实分数/耗时、时间轴和SHA。`chapters.json` 是编辑时间轴。

本机渲染：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 <local-user>/miniconda3/bin/python3.13 -I demo_v2/build_mundisense.py --jobs 3
python3 demo_v2/build_review.py
python3 demo_v2/validate_mundisense.py
```

依赖：NumPy、OpenCV、Pillow、FFmpeg；字体沿用原工程的 macOS PingFang。`--preview --scene 6` / `--scene 7` 可抽帧检查；`--part 6`可单独渲染；`--assemble-only`组装已有分段。缓存按源代码和记录签名复用，修改源媒体后请移除对应 `.build.json` 再重渲染。
