## 2. 逐项判断

1. **墙钟比 1.001。** 多出的 11.3 秒是最后一段在媒体结束后的处理与写出时间。只要有延迟，按"从输入开始到最后一个输出"计算的墙钟就必然大于媒体时长，这是 reviewer 的门槛定义问题。积压曲线全程在 0–1 秒之间，没有增长趋势，说明吞吐已经跟上实时（X06a 的积压呈锯齿状一路涨到 20 分钟）。
2. **延迟 P50 2.2 秒、P95 2.8 秒。** 构成大致为：
   - VAD 以 1 秒为块处理音频，平均带来约 0.5 秒等待（积压在 0–1 秒之间均匀分布，与此吻合）；
   - 端点后准备约 0.68 秒，包括排序与 Q 输入构造；
   - Q-AV 约 0.55 秒；
   - A3 与 V2 约 0.08 秒；其余为调度开销。
   
   前两项还有明确的压缩空间：缩小 VAD 输入块，或在内存中直接构造 Q 的输入，而不是先写成视频文件。但这都需要重新验证 VAD 和 Q 输入的等价性。对"说完话两三秒后显示情绪"这类用途，2.2 秒可以接受；它也不影响 X07（X07 只测准确率）。**接受为已知局限，优化项登记在案，不单开轮次。**
3. **内存增长 11%。** 曲线在前 90 分钟台阶式上升，后 90 分钟持平在约 5.6 GB，更像缓冲区随遇到的最长语音段逐步扩容，而不是泄漏。峰值 5.7 GB，远低于 94 GB。**接受为已知局限**；任何长时间部署之前，需要先做一次 6 小时以上的长时运行测试。
4. **ET-test 上的非劣只报告**：OP-N −0.011 [−0.021, −0.002]，区间整体略低于 0；R90 口径为 −0.003 [−0.011, +0.005]。说明新人脸管线在测试集上可能带来约 1 个百分点的损失。FMH 门槛已通过，按协议不改变结论，记录在案。
5. **切句**：对话时序流上，FMH 损失 −0.015，ET-test −0.025；一对一切中的句子占 66–71%。中性误报为 FMH 14.9%、ET-test 10.7%，回到设计目标附近。AISHELL-4 test 上，0.4 秒最短静音的边界 F1 为 0.486，高于 0.8 秒时的 0.401，帧级 F1 基本不变（0.954 对 0.958）。
