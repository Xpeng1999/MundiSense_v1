# X02 单模态评估协议 v1

本协议在 X02 特征提取和模型训练前冻结。Benchmark v1 的标签、指标和封存集保持不变。折划分见 `configs/folds_v1.json`，SHA-256 见 `configs/folds_v1.sha256`；修改须另建版本。

## 样本与折划分

- CV 池为 EmotionTalk 全部 19,250 句中，说话人不属于 02、13、20、21 的 16,366 句、15 人。02、13 的 val 句也排除。ET-test 1,929 句只作最后一次报告。
- 固定种子 20260928，在 200,000 次仅使用说话人句数的确定性随机分配中选择五个三人外折，先最小化最大与最小折句数差，再最小化平方偏差；平局按说话人 ID 排序。每个外折的内验证三人从其余 12 人中按句数最接近四分之一选取，平局按固定哈希决定。绝不使用标签选择折。
- 外折 holdout 仅用于样本外（OOF）评估。内训练九人用于拟合，内验证三人只用于网格和早停。确定某外折的超参和轮数后，在其余 12 人上重新拟合，再预测该折 holdout。每句恰有一个 OOF 七类概率；失败也保留均匀概率、`status=failed`，在指标中计错。
- 主头均在 M 标签上训练；A/V/T 原生标签只用于同一预测的次要评估，不据此调参。类别权重只从当前训练人员的标签频率计算。

## 选择规则

- A/V 每个编码器均运行 h1 与 h2。h1 是句级均值和标准差（若编码器提供原生句向量也并入）的七类多项逻辑回归；h2 固定为帧级特征的注意力池化、两层 MLP，dropout 0.25。两种头均按内验证 macro-F1、再 UAR 选学习率 `{1e-4, 3e-4, 1e-3}` 与权重衰减 `{0, 1e-2}`；再平局取较小学习率和权重衰减。AdamW、类别均衡交叉熵，无阈值和事后先验修正。
- A/V h1 最多 100 epoch、patience 10；h2 最多 50 epoch、patience 5。每个外折用所选内验证最佳 epoch 在 12 人上重训。最终 ET-test/SIMS-valid 模型的超参，仅按五个内验证分数均值（再 UAR、再较小超参）选；epoch 取对应内验证最佳 epoch 的中位数，在全部 CV 池训练，不看 ET-test。
- T1 为 RoBERTa-large 全量微调，学习率只取 `{1e-5, 2e-5}`、最多 5 epoch、内验证 patience 1。T2 为 BGE 句向量和 h1 逻辑回归，使用 A/V 的 h1 网格。T1/T2 都仅用标注转写训练，外折同时在标注转写 (o) 与 SenseVoice 识别转写 (r) 上预测。ASR 文本只留服务器。T1 最终配置按内验证确定；部署相关的 T 冠军按 CV 的 (r) M 标签成绩选择。
- 每个编码器的头先按 CV 池 OOF M macro-F1、再 UAR 选出；每个模态的冠军再按相同规则在编码器之间选出。A/V 用自身模态 OOF，T 用 (r) OOF。ET-test、SIMS-valid、P1/P2 结果不得进入选择。所有选择及平局记录为 JSON。

## 特征、失败与保存

- 每句特征凭证记编码器 ID、固定 revision、预处理版本、输入媒体 SHA-256、帧率/采样率、特征形状与特征文件 SHA-256。帧级特征和句级统计保留在服务器 `/home/administrator/emotion-data/emotioncore_runs/X02/features/`；仓库只提交路径和哈希清单，不提交转写、媒体、模型权重、逐句特征或逐句预测。
- A2 只加载 Qwen 音频编码器，A3 的若干隐藏层用可学习的全局层权重加权。V1 同时保存人脸帧特征和八类 logits；V3a 与 V3b 使用同一视频的相同采样帧，仅分辨率/人脸裁剪不同。V3a 遵循 X01 `VIDEO_MAX_PIXELS=50176`，V3b 为 448×448。二者的差值在同句上配对 bootstrap 2,000 次。
- YuNet 以 5 fps 检测，用 IoU 连轨；目标轨迹为平均面积乘出现帧比例最大者；外扩 20% 裁剪。无脸句输出七类均匀概率但计作失败，保留在分母。固定种子抽取 60 个多脸句，带框联系表只存服务器。
- 所有媒体解码和预处理由子进程负责，父进程 120 秒硬超时并能终止子进程。正式运行默认拒绝脏 Git 工作区；`--allow-dirty` 必须把完整 diff 保存进 run_meta。失败原因、覆盖率和耗时单独统计。旧项目仅可读文件或权重，绝不在旧目录执行 Python 或导入旧代码。
- OOF、ET-test、SIMS-valid 概率逐句保存在服务器运行目录，每条含 ID、七类概率、状态、模型与配置 ID。仓库仅存路径与 SHA-256。CH-SIMS test 封存集不做推理或特征提取；由于无说话人 ID，无法断言它与 CV 池说话人独立，只能验证 ID/媒体哈希不重叠及无运行产物。

## 指标与探针

- 七类 macro-F1、UAR、WA、逐类 P/R/F1、混淆矩阵、中性误报、覆盖率沿用 Benchmark v1。CV 按 15 名说话人整群 bootstrap 2,000 次并逐人报告。SIMS-valid 用同一最终模型的七类概率定义 `s = P(joy) − P(anger) − P(disgust) − P(fear) − P(sadness)`；Pearson/Spearman 只计有效分数，Acc-2 排除零标签而失败计错。
- P1 在 ET-val 上以未量化 BF16 Qwen2.5-Omni 基座复用 X01 受限首 token 评分、相同提示词和媒体。P2 只尝试 ET-val 三条件；先验证候选标签首 token 唯一性及 32GB 显存可加载性，否则记原因并跳过。两者不用于编码器或分类头选择。
- 文字 CER 在 (o) 与 (r) 间计算，统一 Unicode 规范、去首尾空白，记录空文本与失败分母，并报告总体与逐说话人结果。原文和识别文本均不入库。
