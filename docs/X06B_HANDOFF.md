## 重写时需要保持的接口

- 输入为有原始媒体时间戳的帧、16 kHz 单声道音频和冻结的段边界。当前全局视频网格为 5 fps；人工间隔有 synthetic 标记并保持前帧。
- 每个段的检测缓存保持 frame_index、原始框、JPEG 帧、解码及检测耗时；整段结束后统一排序目标轨迹。不能只凭最后一帧决定目标。
- 当前轨迹分数、目标选择和 `selected_indices` 来自 X02。改写后至少保留 target_score、第二轨迹分数、target_presence_fraction、crop_paths、whole_paths、requested_frames、decoded_frames，以及缺脸原因；新质量指标另加字段，不暗改原含义。
- 多脸判据固定为 second_score ≥ 0.5 × target_score。无脸但有语音走 H_A；有脸无语音每 2 秒走 H_V/OP-R80；无模态拒识。不要把多个瞬时人脸数直接等价为歧义轨迹。
- Q 输入沿用 X03 的八帧视频构造；A3/V2/V1 沿用冻结预处理及 D1_fmhx。默认 H3 一次 Q-AV，H_ref 为 Q-A 与 Q-AV。只能使用系统实际需要的分量。
- 输出事件包含时间戳、来源、语音/静默标记、起止时间、路由、标签或拒识、置信度；附加分量概率和运行凭据用于审计。EMA 在校准后、偏置与阈值之前进行，静默事件不推进语音状态。
- 不覆盖旧实验产物。每次正式运行须干净提交、输入/模型/参数 SHA、run_meta、GPU 账本和逐句结果路径。

## 等价性检查方法

修订 1 区分 S6a 与 S6b。S6a 比较完全相同输入、去掉全部守门后的代码输出，要求一致率 1.000；原始单句服务诊断已经满足，不重跑。相同输入而输出不同仍是立即停止条件。

S6b 衡量句尾补零和全局抽帧相位变化后的稳健性：在 FMH 正确切句流上比较与离线参数包决策的 OP-N macro-F1，按句配对 bootstrap 2,000 次、seed 20261011，95% percentile 区间下界 ≥ −0.02 为验收项；H3 点估计 < −0.05 才立即停止。多脸规则排除在 S6b 外，单独按 S3 的 FMH ≤ 5% 判断。ET-test 仅报告，保留既有 1,184 句并补剩余 745 句；原 0.95 / 0.99 标签一致率门槛不再使用。

按层核查接口：帧时间戳与像素 → 检测框和轨迹分数 → 目标裁剪字节 → 分量概率 → 校准后概率 → 路由与拒识标签。X06b 重写时用相同输入验证代码等价性，再单独评估有意输入变化带来的准确率和覆盖率差异，不把二者混为一个门槛。X06a 修订 1 没有授权重写 X02 人脸管线。

已有 23 项通过的协议测试、两句 FMH CPU 裁剪字节核对，以及原 0.8 秒配置七条流在线/全速时序核对；0.4 秒只计算了缓存后验的段数，还未完成媒体准备或在线时序核对。最短静音尚未按 FMH 情绪选定，也没有 EMA 冻结文件。
