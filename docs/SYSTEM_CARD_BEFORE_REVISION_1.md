# 系统说明卡：声音与画面的情绪识别

版本：X06b 冻结系统 / X07 因流程自检停止，2026-10-14。面向非技术读者。

**能做什么。** 输入一个人的说话声音和面部视频，输出中性、喜悦、悲伤、愤怒、恐惧、厌恶、惊讶七类判断及置信度。把握不足或画面中人物难以区分时拒绝判断；没有可用人脸时可退回声音判断。它判断的是可听、可见的情绪表达，不是人的内心状态或医学诊断。

**已测得的表现。** F1 综合衡量各类别的识别效果，越接近 1 越好，不能直接当作“正确率”。

| 数据 | 测什么 | 结果 |
| --- | --- | --- |
| ET-test，1,929 句 | 七类情绪 | 平均 F1 0.645；按固定拒识点为 0.642，覆盖 88.5% |
| FMH，3,266 句 | 七类情绪，参与过校准与选择 | 平均 F1 0.697；按固定拒识点为 0.668，覆盖 90.0% |
| CH-SIMS v2 test，1,034 段 | 情绪倾向的正负与强弱 | 未测；流程自检在推理前停止 |

前两行直接引用 X06b 的完整句子对照（未应用多人脸门禁；拒识片段计入 F1 分母）。CH-SIMS 的标签是从负面到正面的连续倾向，没有上述七类标签；其结果只能补充说明换一个语料后的表现，不能证明真实用户效果。

**速度与设备。** 已在 RTX 5090 32 GB GPU、约 94 GB 内存的工作站上运行。三小时回放能跟上输入，计划语音端点至输出的典型等待约 2.2 秒，95% 约 2.8 秒。进程内存峰值约 5.7 GiB；前约 90 分钟增长 11% 后持平。长时间部署前仍需一次超过六小时的运行测试；这些数值不是普通电脑或手机的性能保证。

**使用边界。** 尚未在真实设备和真实用户场景验证；仅面向单人，不能可靠处理多人交谈或判断谁在说话。单独依靠画面较弱，遮挡、侧脸和缺失媒体会影响结果。换语料后，同一拒识阈值保留的片段比例可能改变，因此“90%”不是任何场景都能保证的覆盖率。现有数据许可禁止商用。本系统尚不是面向公众的任意视频上传服务。
