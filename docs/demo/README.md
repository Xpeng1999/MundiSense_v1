# MundiSense v1 demonstration

104.167 seconds, 1920 × 1080, 30 fps, H.264/AAC. Six EmotionTalk clips and two CH-SIMS v2 clips replay saved model outputs with original source audio. Source media plays at its original speed; editorial holds and schematic 3D animation are not inference timing or neuron activations.

The final two examples show audiovisual sentiment comparison and ambiguous-multiple-face abstention. The CH-SIMS clips have sentiment annotations, not seven-class emotion ground truth. The closing R4 metrics are measured over the full 1,929-utterance EmotionTalk cohort, not the curated clips.

`chapters.json` supplies navigation times. `source_manifest.json` records the source identities, hashes and output records with local workspace prefixes normalized. `verification.json` records the full-decode and retained-data checks.
