# MundiSense v1 release contents

This public research release includes the project implementation and experiment records already retained in this repository, an English technical report, five owner-supplied method diagrams, two data-derived plots, and a 104-second demonstration of saved inference results. EmotionCore remains the internal implementation/package name.

The main runtime implementation is retained as code. Q_mix adapters, expert checkpoint weights, upstream model weights, full datasets and the original business-plan deck are not part of this documentation/media release. Existing experiment branches remain available as historical records; the release does not merge or rerun them.

No new software or dataset license is granted by the visibility change. Upstream models, datasets and original footage retain their own terms. The original X01 setup and provenance limitations remain in [X01_REPRODUCTION.md](X01_REPRODUCTION.md). See the report for evaluation definitions and scientific limitations.

The five method diagrams were supplied by the project owner after generation from project-specific prompts. They are conceptual illustrations, not experimental measurements. Numerical plots are generated from retained result files. Image-source and evidence hashes are recorded beside the report.
